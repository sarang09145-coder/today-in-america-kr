# Notification Plan

## 목표

사용자가 관심 지역과 카테고리를 선택하면, 하루에 제한된 횟수로 짧은 뉴스 알림을 보낸다.

## 원칙

- 사용자가 명확히 허용한 경우에만 알림을 보낸다.
- 첫 방문 직후 권한 요청을 띄우지 않는다.
- 알림 문구는 짧게 유지한다.
- 기사 전문 또는 자극적인 사건 세부 내용을 알림에 담지 않는다.
- 알림을 누르면 원문이 아니라 서비스의 이슈 카드로 이동한다.
- 서비스 안에서 다시 원문 기사 보기 버튼을 제공한다.

## 알림 예시

```text
오늘 미국 주요 뉴스 5개가 업데이트됐습니다.
```

```text
조지아 지역 뉴스가 새로 올라왔습니다.
```

```text
관심 카테고리 ‘경제·시사’에 새 기사 링크가 추가됐습니다.
```

## 피해야 할 알림

```text
범죄 사건의 구체적인 신상, 혐의, 피해 내용을 자극적으로 요약한 알림.
```

## 구현 예정

- Service Worker
- Push API
- Notification API
- VAPID keys
- 사용자 관심사 저장
- 알림 수신 해제 기능
