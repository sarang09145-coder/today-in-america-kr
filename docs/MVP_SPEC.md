# MVP Spec

## 목표

한국어 사용자가 미국 뉴스를 빠르게 발견하고 원문 언론사 사이트로 이동할 수 있는 안전한 큐레이션 MVP를 만든다.

## 사용자 흐름

1. 사용자가 메인 페이지에 들어온다.
2. 오늘의 미국 요약을 확인한다.
3. 언론사, 주/지역, 카테고리를 선택한다.
4. 짧은 한국어 안내문을 읽는다.
5. 원문 기사 보기 버튼을 눌러 원문 사이트로 이동한다.

## 핵심 화면

### 메인 페이지

- 서비스 소개 문장
- 오늘의 미국 요약
- 필터 바
- 이슈 묶기 카드
- 기사 카드 목록

### 필터 바

- 출처 선택
- 지역 선택
- 카테고리 선택
- 민감 기사 포함 여부

### 기사 카드

- 카테고리
- 지역
- 출처
- 게시 시간
- 자체 한국어 제목
- 짧은 한국어 안내문
- 태그
- 원문 기사 보기 버튼

## 성공 기준

```text
[ ] 샘플 데이터로 메인 화면이 작동한다.
[ ] 필터링이 작동한다.
[ ] 기사 전문 또는 전문 번역이 없다.
[ ] 원문 링크가 모든 카드에 있다.
[ ] 민감 기사 표시가 가능하다.
[ ] 샘플 데이터 검사 스크립트가 통과한다.
```
